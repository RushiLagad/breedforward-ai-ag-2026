# Contributing

Four people, one weekend. Everyone is a collaborator with push access.

- Work on `main`. Small commits, pushed often. No long-lived branches.
- Say in the channel before editing a file someone else is in.
- Never commit anything from `data/` or `results/`. Summaries go in `results_summary/`.
- A number goes in the deck only after a second person reproduces it from this repo.
- Commit messages in the imperative: `Add sampling curve`, `Fix C2 line key`.
