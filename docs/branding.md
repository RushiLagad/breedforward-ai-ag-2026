# BreedForward identity

## Team name

**BreedForward**

**Tagline:** *Grounded in data. Breeding for the future.*

The name is concise and future-facing. It connects breeding with the team's goal of using AI and data to move agricultural decision-making forward.

## Logo concept

- DNA helix: genetics and breeding
- Data nodes: AI, computation, and analytics
- Green leaves: agriculture, growth, and biological improvement
- Forward arrow: progress, translation, and future impact
- Navy and green: scientific credibility and agricultural growth

## Files

| File | Use |
| --- | --- |
| `assets/breedforward-logo-white.png` | Official submission, README, email, and presentations |
| `assets/breedforward-logo-transparent.png` | Layouts that already have a light background |

The transparent file can become difficult to read on dark backgrounds. Use the white-background version by default and do not stretch, recolor, crop, or rearrange the logo elements.

The team name is confirmed. The current logo remains subject to final team approval before submission to the organizer.
